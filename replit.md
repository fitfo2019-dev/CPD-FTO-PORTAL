# FieldReady — Field Training

Offline-first field training development foundation with fictional DORs and encrypted local drafts. Not approved for operational or CJIS-restricted data.

## Run & Operate

- `pnpm --filter @workspace/api-server run dev` — run the API server (port 5000)
- `pnpm --filter @workspace/field-training run dev` — frontend, via its configured workflow
- `pnpm run typecheck` — full typecheck across all packages
- `pnpm run build` — typecheck + build all packages
- `pnpm --filter @workspace/api-spec run codegen` — regenerate API hooks and Zod schemas from the OpenAPI spec
- `pnpm --filter @workspace/db run push` — push DB schema changes (dev only)
- Required env: `DATABASE_URL` — Postgres connection string

## Stack

- pnpm workspaces, Node.js 24, TypeScript 5.9
- API: Express 5
- DB: PostgreSQL + Drizzle ORM
- Validation: Zod (`zod/v4`), `drizzle-zod`
- API codegen: Orval (from OpenAPI spec)
- Build: esbuild (CJS bundle)

## Where things live

See `docs/PROJECT_STRUCTURE.md`. Portable SQL is in `database/migrations/001_field_training.sql`; encrypted storage is `artifacts/field-training/src/lib/offlineStorage.ts`.

## Architecture decisions

- Initial deliverable is explicitly fictional/local; no live report backend or identity integration is connected.
- Never claim CJIS compliance from framework choice, encryption, or hosting provider alone.
- Preserve portability to standard government/on-premise PostgreSQL and self-hosted infrastructure.

## Product

Dashboard, DOR builder, training competencies, sequential demonstration signatures, local passphrase vault, night-shift mode, and production PWA shell.

## User preferences

STRICT USER REQUIREMENT: Never use numerical performance ratings, numeric score averages, or performance percentages. Use only NO (Not Observed), A (Acceptable), RT (Responding to Training), UA (Unacceptable), and NRT (Not Responding to Training). This rule overrides any conflicting numeric-scale text in supplied briefs. Display actual rating badges in summaries, not converted scores.

## Gotchas

Read `docs/SECURITY.md` before connecting real identity, sync or databases. SQL triggers/grants are supplied as portable source, not installed in a live database. Production PWA shell is generated by `pwa-plugin.ts`; development does not register a worker.
