# FTO LAW LIBRARY SCHEMA

Use `docs/AGENTS.md` and the source-backed family references before authoring UI.
This package extracts the selected Law Library Resource Preview, not the portal's
entire component catalog. Existing screens must not change without approval.

## Source-derived design guidance

- Use indigo emphasis on pale paper/white surfaces; navigation selection uses a
  soft indigo background.
- Use Manrope for headings, DM Sans for body, DM Mono for metadata.
- Resource cards present title, collection and optional note without document
  content. Keep unavailable-document actions explicitly disabled in previews.
- Retain compact cards, subtle borders, focus indicators, responsive single-column
  cards and reduced-motion behavior.

The source has no separate written brand guidelines. These observations come
from its CSS and composition, not an official Columbus branding standard.
Dark mode is derived. This design system changes no security or storage rules.
