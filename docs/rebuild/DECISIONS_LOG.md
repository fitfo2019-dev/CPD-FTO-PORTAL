# FTO Portal Rebuild: Decisions Log

This is the owner's decision record. When rows conflict, the later row wins. A row marked as asked, pending, open, preview only or awaiting approval is not a decision yet. Copied from the project files; Perplexity keeps this copy current.

Goal: rebuild the whole website with a strong UI, keep every existing goal and workflow, and cut the time FTOs spend on paperwork. Forms on screen may be revised, but they must capture all of the same information. Printed and exported PDFs keep the official one-page layouts (to be confirmed in Set 12).

Reference: existing portal source (Field-Training-Portal-Source-Code.zip) and the Completed Build Dossier (108 merged tasks, snapshot 2026-11-25).

## Set 6: Daily ratings (in progress, November 25, 2026)

Rating codes (from the existing portal and FTO Manual glossary): NO Not Observed, A Acceptable, RT Responding to Training, UA Unacceptable, NRT Not Responding to Training.

### RT / NRT progression rule (user-defined)
| Topic | Decision |
| --- | --- |
| After a UA | In that category, the 1st and 2nd acceptable performances after the UA are rated RT. The 3rd acceptable returns to A. |
| What counts | Each run counts as one acceptable, so the progression can advance more than once in a shift. |
| Escalation | Three UAs become NRT, and the Coordinator receives an alert to review it and suggest a meeting. (Resolved in Set 6: the 3rd UA in the same category in the same phase opens an NRT review.) |
| Restricted categories | Follow the FTO Manual. The 2026 manual is needed to confirm whether RT stays blocked in Officer Safety, Driving Skills and Report/Prepared for Duty (the current code blocks it, citing the 2025 manual). |
| Scope | The count resets at the start of each phase. The FTO can override a suggested rating with a reason. |
| RT change alert | When the portal changes an A to RT because of an earlier UA, the FTO is alerted on that rating row and again in the CONFIRM RATINGS step. The alert shows the category, the date and run of the UA, and the count (for example, "Acceptable 1 of 2"). Data only, no rule text. Only the FTO sees these alerts. The Coordinator sees RTs in the summaries and gets alerts only for NRT. |

### Manual findings for Set 10
- Reporting for Duty: "There must be a Reporting for Duty for each day to account for the PO's whereabouts and/or the reason PO was not present." The reason (training type and hours, sick, leave) goes in the Appearance/Equipment narrative.
- Phases: the PO moves to the next phase automatically unless the FTO recommends ceasing training. The manual has no extension procedure.
- Back-to-back phases need FTO Sergeant permission. Phase IV is generally senior FTOs only (4 previous coaching phases as the assigned FTO).
- Weekly Log date: use the Sunday of that training week.
- FTO incentive: on a 5x8 schedule, 12 vacation hours per 20-day phase when the FTO coached at least 17 days (Phase IV: 8 hours for 14 of 15). On a 4x10 schedule: 13 of 16 (Phase IV: 11 of 12). Phase stipends: $1,600 / $2,400 / $3,600 / $2,400 / $1,600, counted by the calendar year the phase began.

## Set 10: Phase setup (November 25, 2026)
| Topic | Decision |
| --- | --- |
| Non-release notice | Coordinators (and the FTO Sergeant) are notified as soon as the FTO selects the non-release statement. The Phase IV FTO is prompted to choose a Week 15 statement 2 weeks before W15, 1 week before, and 2 days before. Prompts stop once a statement is selected. |
| PO not working | The FTO chooses either option: create that day's Reporting for Duty page with the reason in the Appearance/Equipment narrative, or mark the day only. Either way the day is excused from the day-count check. |
| Extensions | The Coordinator enters extension days directly. Later dates, W# numbering and sign-up dates shift automatically. |
| Sign-up fairness (user) | No Sergeant approval. The goal is fairness and less FTO fatigue. An FTO who has not just coached gets priority over one who coached the previous phase. A gap resets this: coached Phase 1, skipped Phase 2, signs up for Phase 3, so treated as not having coached. Back-to-back coaches are not blocked and can sign up for the following phase. Detailed system proposed in Set 10b. |
| Senior FTO threshold | 4 completed full phases as the assigned FTO (manual). Senior status is set automatically. |
| Full phase (live portal) | Assigned FTO for the phase and meets the incentive day threshold: 5x8 = 17 of 20 (Phase IV 14 of 15); 4x10 = 13 of 16 (Phase IV 11 of 12). Coverage days count toward the covering FTO's day totals, not as a phase. |
| Launch seeding (user) | The FTO self-reports and a Coordinator verifies. To claim senior, the FTO enters the name and badge number of at least 5 POs they have coached. Five gives a buffer in case one was not a full phase. The Coordinator confirms each entry; Senior requires 4 confirmed. |
| Launch entries | Name and badge only, per prior PO. |
| Matching | "Rested First" approved. When the sign-up window closes, rested FTOs (did not coach the immediately preceding phase; a gap resets) are matched first. FTOs see CONFIRMED with the PO's name or WAITLISTED #n (the waitlist moves up automatically). Coordinators can change any match. |
| Tie-breaker | Longest time since the last phase ended, then fewest phases this calendar year, then earliest sign-up. |
| Phase IV | Senior FTOs are matched first, then non-senior if POs remain. Rested-first applies within each group. |
| Variety | After the fairness order, prefer an FTO whose watch and precinct the PO has not had. Never overrides fairness. |
| Manual: new FTO each phase | "Each training phase will offer a new FTO and assignment to the PO" (different FTOs, duty hours, patrol zones and precincts). |
