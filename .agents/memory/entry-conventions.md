---
name: Portal entry conventions
description: User-requested keyboard entry and orientation task presentation rules.
---

All portal date/time fields should offer current local values by entering a question mark and pressing Tab. A date field fills the current date, a time field the current time, and a combined field both; normal Tab navigation should continue.

**Why:** The user explicitly requested the shortcut in all portal date/time fields.

**How to apply:** Preserve this shortcut when adding or changing editable date/time inputs. Existing record-date restrictions still apply; the shortcut is not permission to bypass them.

Orientation tasks should all be placed with the most similar items in existing categories, not presented as standalone single-task boxes or extra section titles. Use equal-sized boxes without orphaned grid spaces. New orientation substation entry should appear blank and populate station details only after a number is entered and Tab or Enter is pressed.

**Why:** The user corrected the standalone presentation of BWC Tower and Precinct specific information, then specified that all singles belong in existing categories to avoid unfilled spaces and multiple titles.

**How to apply:** Consolidate the on-screen presentation while preserving saved individual task values and the existing printed form. Preserve saved station values when reopening existing records.
