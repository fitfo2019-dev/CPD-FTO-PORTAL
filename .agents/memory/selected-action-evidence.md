---
name: Saved action evidence boundary
description: Rules for weekly and class views of specific saved missed actions.
---

Recurring-action summaries must use only explicit, saved action choices from source run forms. An unchecked task without selected sub-actions is not an action occurrence for this view. Keep the summary read-only: do not generate narratives, alter SEG ratings, infer additional failures, or claim training occurred.

**Why:** The user requires recurring evidence to reflect saved selections only and remain separate from ratings, narratives, and training records.

**How to apply:** When building rollups or exports of specific misses, retain each saved action’s source report, run, form, and page reference; count selected-action occurrences separately from SEG rating totals.
