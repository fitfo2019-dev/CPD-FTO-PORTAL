---
name: Traffic-stop entry sequence
description: User-required 10-6 prompt sequence and exclusive primary-form selection.
---

Enter or record 10-6 first, then ask whether the stop was high risk in a separate popup—not an inline question on the run page. Yes opens only the existing High Risk Traffic Stop form; No opens only the ordinary Traffic Stop form.

**Why:** The user explicitly required a natural sequential flow rather than putting the high-risk question on the same page.

**How to apply:** Preserve this sequence in manual and dispatch-prefilled traffic-stop entry. A dispatch code is not itself a high-risk decision. Keep existing checklist-change confirmation safeguards when editing saved work.
