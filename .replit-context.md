## 3. VERSIONED CLEARANCE RULES & ACTIVITY TOTALS
Automatic clearance-derived report and citation counts apply only to `clearanceRulesVersion: 1` runs that are complete and explicitly checklist-reviewed. Separately, an explicitly saved `arrestClassificationVersion: 1` on a reviewed 3V contributes its one severity count and, for Warrant, one warrant-served count. Unclassified legacy runs are not reclassified or recounted automatically; editing one does not backfill its old clearance multipliers.
* 1V: An explicitly selected Traffic Citations metric contributes one citation. Otherwise, a Traffic Stop or selected Solve Citation/Summons metric contributes one Solve Citation/Summons; other runs contribute one PremierOne Report. Distinct citation columns are not incremented together automatically.
* 2V: No automatic report or citation count.
* 3V: Transport starts unchecked on a new run. Selecting Arrest Made or 3V preselects transport and 3V. The FTO records the actual transport destination and destination type. If transport is cleared, the code changes to 1V; validation requires 1V for an arrest without transport and requires a destination for a transported arrest. A newly reviewed 3V arrest also requires explicit Arrest severity (`Felony` or `Misdemeanor`) and Arrest type (`Warrant` or `On-view`); F/M and W/O shortcuts expand case-insensitively. Each reviewed arrest contributes exactly one severity count, and a Warrant contributes one warrant-served count. A Warrant does not create a new Probable Cause Affidavit; On-view retains one. Neither charge lines nor classification values create criminal-complaint counts or complaint drafts. Existing saved charge detail is preserved. Editing a legacy 3V does not backfill its old clearance multipliers; severity/type counts appear only after the FTO explicitly records and reviews those classifications. No classification is inferred.
* 4V: Timeline evidence only; it adds no report/citation multiplier.
* Manual activity entries and eligible derived counts are combined for displayed totals. Editing a displayed total changes its manual portion; it cannot erase an eligible derived count. Run activity flags remain supporting evidence and do not duplicate clearance-derived totals.
